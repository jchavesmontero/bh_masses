# Example data

* `minijpas_qso_examples.cat` — three SDSS quasars observed by miniJPAS (the
  examples shown in Chaves-Montero et al. 2022), with aperture-corrected
  fluxes (erg s⁻¹ cm⁻² Å⁻¹) in all J-PAS bands and SDSS redshifts (`zspec`):

  | row | miniJPAS Tile-ObjID | SDSS plate-mjd-fiber | z |
  |---|---|---|---|
  | 0 | 2406-853   | 7339-56722-0108 | 0.676 (Hβ, MgII) |
  | 1 | 2241-15867 | 7339-56722-0153 | 1.605 (MgII, CIV) |
  | 2 | 2243-14873 | 7339-56722-0147 | 3.218 (CIV) |

* `spec-*.fits` — the corresponding SDSS DR16 spectra, used only for visual
  comparison.
